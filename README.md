# Arc — Personal AI Assistant

Arc is the personalized name of the AI assistant.

## Run
1. Install Node.js.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Set `OPENAI_API_KEY` as an environment variable.
5. Run `npm start`.
6. Open `http://localhost:3000`.

The website lets the user save their name locally in the browser. Never put an API key in frontend code.
